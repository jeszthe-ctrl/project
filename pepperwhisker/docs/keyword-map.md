# Pepper Whisker keyword map

Every keyword group from the research list is assigned to **one** page, so pages never compete with each other. Volumes are monthly US searches from the list.

## How to use this map

1. **Check search intent.** Search each group's main keyword on google.com (signed out, US) and look at the top 10. Listings in the results → the puppies page; articles → a guide.
2. **Watch Google Search Console → Performance → Queries** after 4–8 weeks. If Google shows a different page for a group, strengthen the intended page (title, headings, internal links) instead of adding a new one.
3. **Add first-hand evidence** to the selling pages: your own puppy and parent photos, videos, health results and real reviews.
4. **One page per group.** No near-duplicates for small wording changes ("mini schnauzer for sale" vs "miniature schnauzer for sale").

## Left out on purpose

- **Prices** ("miniature schnauzer price", "giant schnauzer cost", "$400 puppies"): prices are listed with each puppy; there is no separate price page.
- **"lalune miniature schnauzer coat color"**: a third-party brand name, not ours to target. The colors guides cover coat colors.
- **"miniature schnauzer images / pics"**: answered by real puppy photos on the puppy pages, not a separate page.
